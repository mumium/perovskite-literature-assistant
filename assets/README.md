# 钙钛矿文献助手 Logo

当前品牌图形为明显翻开的书本与平面菱形结构组合，保留金色中心点。按用户最终偏好采用平面图形，不表现立体八面体；这是品牌图形示意，不是晶体结构教学图。

v0.6主页面使用 `logo-book-octahedron.svg` 矢量重绘，以高DPI像素渲染，避免小图拉伸模糊。原PNG与标题栏/EXE的ICO继续保留。工具栏图标由perovskite/ui_icons.py内的SVG线条生成，不依赖字体或网络资源。

`logo-book-octahedron.ico` 含16、24、32、48、64、128、256像素图标，已接入Windows exe、窗口和程序页头。PNG保持生成时的透明通道，ICO仅做格式和尺寸转换。

使用内置image_gen工具生成及编辑，所选平面版本的生成提示词见 `logo-prompt.txt`。早期 `logo-v1` 及 `logo-octahedron-3d-draft.png` 保留为设计历史，当前程序不使用。
