- “阅读模式”后新增同尺寸渐变按钮。点击“加速浏览”后仅缩放固定预览图片，按钮变为“高清浏览”；再点恢复当前高清补绘方式，保留原文、缩放、位置及批注。

91项测试及Windows单文件exe离线隔离验收通过，实际检查深浅主题、两种模式、按钮尺寸及重启设置恢复。测试使用明确标注的合成文档；未在全新Windows虚拟机或公司受限电脑验收。
