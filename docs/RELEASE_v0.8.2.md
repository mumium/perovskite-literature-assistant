# 钙钛矿文献助手 v0.8.2 · MK Design

修复批注字体增大箭头不容易点中的问题。字号框扩大为88×30逻辑像素，右侧明确分为右上增大、右下减小的22×15点击区域，带悬停与按下反馈，每次调整1点；也可直接输入字号。

手动分类名称支持双击就地修改，Enter保存、Esc取消；文献计数不进入编辑框，空名称和已有同名类别会拒绝并说明原因。“全部文献”和“未分类”保持固定，改名不改变文献归属或当前详情页签。

实际鼠标点击字号箭头中心和靠边位置，检查增减字号及数据库样式同步保存；实际双击类别编辑并验证Enter/Esc、空名称校验和归属保持。77项回归测试及Windows单文件exe离线隔离验收通过。测试采用合成文档，未在全新Windows虚拟机或公司受限电脑实测。

保持原任务栏同款高清logo、MK Design签名及现有功能。数据结构不变，关闭旧版后双击新版，继续使用原数据目录即可。
