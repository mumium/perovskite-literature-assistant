# 后续功能与使用场景

本文件是功能建议，不代表已实现。当前版本已提供文献管理、分析包交换、阅读卡、按样品的工艺/性能数据、证据定位、全文检索、导出，以及原文缩放/高亮批注。下面按科研工作环节提出进一步值得开发的能力。

| 优先级 | 建议功能 | 具体使用场景 | 设计重点 |
|---|---|---|---|
| 高 | 正文与SI并排阅读 | 正文提到某个添加剂效果时，同时对照SI中的浓度组、制备细节和对照实验 | 两个附件独立翻页/缩放，证据链接可跳转，不猜测页码对应 |
| 高 | 复现实验清单 | 决定复现一篇文章前，汇总原料、操作步骤、设备、关键参数和未报告条件 | 按样品生成；缺失条件单列，绝不补造配方 |
| 高 | 文献方案与自己的实验对照 | 把实验室实际配方、批次、环境和性能与文章工艺并列，解释复现偏差 | 文献值与自测值明确区分，保留仪器/测试条件及原始数据来源 |
| 高 | 待核验任务清单 | 集中处理“添加剂5%基准未知”“正文/SI退火温度冲突”“缺少稳定性封装条件” | 每项能跳回原文，记录处理决定与理由，不靠AI自动消除冲突 |
| 高 | 参数别名与单位审查 | 同一添加剂/材料在多篇文献中有缩写、商品名和化学式，检索容易遗漏 | 用户维护别名表；换算保存基准和维度，未知比例不混算 |
| 高 | 逐字段编辑表单 | 不写JSON也能修订作者、工艺步骤、参数、证据、性能条件 | 保留现有结构校验、来源和修订历史 |
| 中 | 跨文献证据矩阵 | 比较多篇对同一机制的主张、实验手段、对照和反例，准备综述或课题设计 | 作者主张、直接结果、推测分开；不同体系和测量条件分组 |
| 中 | 图表索引与局部截取 | 组会快速定位XRD、PL、能级图、器件统计和稳定性曲线，并记下自己的判断 | 截图和笔记绑定文件/实际页/区域；保持原图，不自动上传 |
| 中 | 选题决策记录 | 记录“为什么值得复现”“为什么放弃”“哪些证据不足”“下一步验证什么” | 决策有时间和依据，形成自己的研究路线历史 |
| 中 | 专题阅读队列与组会包 | 为“埋底界面”“氯化物添加剂”等专题安排必读/待读，输出带来源的组会提纲 | 优先本地管理；幻灯片/AI生成作为可选步骤，不能冒充读过全文 |
| 中 | BibTeX/RIS及引用检查 | 写论文或综述时将文献库导入常见写作工具，并核对DOI、作者和发表日期 | 缺失字段显示缺失，不创建虚假期刊、卷期或日期 |
| 中 | 负面结果与适用边界库 | 保存自己做过但无提升的实验、失败批次、文献中不利条件，避免重复踩坑 | 与冠军性能分开，注明是否公开文献或内部实验记录 |
| 中 | 原料与设备批次记录 | 同配方在不同供应商、纯度、批次或设备上结果不同，追踪可疑来源 | 所有批次信息来自实际记录，未知留空 |
| 中 | 更正、撤稿与新版本主动检查 | 在家用联网电脑定期检查已关注文献是否有更正或新版本 | 默认离线；用户主动触发联网；保留原版本，不自动删除文件 |
| 中 | 团队只读分享与审阅包 | 给同事或学生分享某专题的精选文献、批注、待核验问题，带回审阅意见 | 分享前预览内容与附件版权；不直接并发编辑同一SQLite目录 |
| 后续 | 扫描件OCR与表格辅助提取 | 老论文、扫描SI、图片配方表不能复制文字，需要补充定位与人工核验 | 便携OCR组件可选；报告识别误差，原图与识别文本并存 |
| 后续 | 仪器数据与文献证据关联 | 将自己实验的CSV、曲线、照片和处理脚本绑定到样品和结论 | 原始数据不可覆盖，计算过程有版本和参数记录 |

建议下一阶段先做“并排阅读 → 逐字段表单 → 复现实验清单 → 自己实验对照”。这几项能直接连接读文献和开展实验。向量检索、自动推荐或知识图谱可等数据质量和核验流程稳定后再考虑。
