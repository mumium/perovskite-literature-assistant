# 钙钛矿文献助手 v0.10.0 · MK Design

- 顶部图标默认无框，鼠标悬停显示淡蓝底色，按下时加深，深浅模式均有可见反馈。右侧仍是“文献信息、核心故事、工艺”等文字标签页。
- 已打开的PDF在本次运行中复用页面、绘制指令、高清区域、缩放与阅读位置，返回缓存原文时立即显示；未完成的只补剩余页。PDF/DOCX往返、选择无附件文献后返回也可复用，DOCX保留提取文本的文档对象与位置。
- 默认缓存最近12份PDF，预览与高清图像合计预算1GiB；达到上限释放最久未访问项并提示。DOCX最近12份、文本占用估算64MiB。文件变化后重新校验；关闭或换库时释放缓存，重启后首次阅读仍需加载。

86项测试通过。两份合成PDF往返切换实测约7–11毫秒，检查过程禁止重新打开PDF、完整哈希和页面预载；该耗时仅代表测试样本及当前电脑。Windows单文件exe通过离线隔离验收，检查缓存立即恢复及深浅主题截图。未在全新Windows虚拟机或公司受限电脑验收。

关闭旧版后双击新版，继续使用原数据目录即可。数据库结构不变。
