# 钙钛矿文献助手 v0.7.0

左侧新增手动分类，PDF改为整篇后台预加载。

- “手动分类”旁＋创建类别，✎改名、−删除；也可右键操作。按住清单文献拖入类别，Ctrl/Shift可多选。一篇文献可属于多个类别。
- 点击类别筛选，未分类查看尚未归类文献；右键移出，全部文献或清空退出筛选。分类可叠加全文和字段检索，切换仍保留当前详情页签。
- 分类操作不复制、移动或删除附件；删除类别保留文献。分类随数据目录、完整备份、Markdown和Excel关联表保存。
- PDF打开时后台预加载全部页，记忆的当前页优先。显示进度，可暂停/继续；失败页显示原因、可重试，已完成页面不重复处理。
- 全部页图像保持在内存，大幅跳页和缩放直接复用，不再清掉远处页或按需重绘。切换附件和退出释放图像。
- 初次整篇加载时间取决于页数与图片复杂度。全文图像预算512MiB，文字坐标和程序其他内存另计；超长PDF会明确提示分辨率调整，仍加载全部页。极高倍缩放受预载图像分辨率限制。
- 旧库自动升级到v3，升级前在数据目录migrations保存快照。继续打开原数据目录即可，交换格式1.0不变。

69项自动化测试通过。Windows单文件exe另进行离线隔离启动验收：只复制exe、移除外部Python/Office运行环境路径、阻止网络，检查分类、全文预载、原文及DOCX、高亮持久化、标准PDF批注、导出和临时目录清理。所有验收文档明确为合成测试。未在全新Windows虚拟机或公司受限电脑实测。

下载 `perovskite-literature-assistant-v0.7.0-windows-x64.exe`，双击即可。不要同时编辑同一数据目录。默认离线、无OCR、不内置模型。
