附件关联改为直接从电脑选文件，并记住上次数据目录。

1. 左边点正文文献，点“关联附件”，在Windows文件选择窗口多选PDF、DOCX或DOC，角色默认SI，确认后自动导入并关联。不再从文章列表里选择关联目标。
2. 已导入的相同文件复用；原本属于其他文献的附件会移入当前文献并解除原关联。批次失败显示原因，可取消或重试，原文件不改动。同一已确认关联重复选择不会重置已核验分析。
3. 首次选择数据目录后自动记住，下次启动直接打开。“更多 → 切换数据目录…”可换库，目录失效才重新选择；不移动或删除旧数据。
4. 位置记录优先放exe旁并使用相对路径，程序目录只读时放本机用户目录，不写注册表或临时解包目录。

54项自动化测试，包含真实程序入口切换库后重启不再选择、目录搬移及只读回退。Windows单文件exe仍无需Python、Office或数据库安装。

更新时替换exe并保留已有数据目录；本版本首次运行需要选择一次，之后自动记忆。无OCR，旧DOC仅保存并明确提示不支持；DOCX批注暂不写回原Word文件。所有测试文档均为合成样本，未在干净Windows虚拟机或企业白名单环境验收。
