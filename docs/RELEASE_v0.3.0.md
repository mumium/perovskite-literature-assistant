高亮与批注可以保留在PDF文件里，在其他支持批注的阅读器中查看。

- 在“原文查看”保存高亮后，点击“另存带批注 PDF…”生成独立文件；或点击“写回原 PDF…”选择最初导入的原文件。
- 写回前自动备份到数据目录pdf_backups，完成后显示备份路径。
- 重复保存更新本工具标注，删除高亮也可同步；其他阅读器原有批注保留。
- 错误文章、外部修改过的目标、受管理原文副本会拒绝覆盖；后台可取消。
- 库内原文副本保持原哈希，不影响已有分析包和证据定位。数据目录中的备份、保存记录与批注副本纳入完整备份。
- 42项自动化测试通过，包含PDF标准高亮/中文评论重开校验、更新与删除、其他批注保留、备份恢复及后台保存。

使用端无需安装Python、Office或数据库。原来的数据目录可继续使用。

限制：DOCX原文件写回暂未实现；数据库标注需要点击文件保存按钮才会同步到PDF；外部软件修改过的目标不会自动覆盖，可另存新副本；不同阅读器的评论面板操作有所不同。无OCR，未验收所有第三方阅读器或干净Windows虚拟机。
