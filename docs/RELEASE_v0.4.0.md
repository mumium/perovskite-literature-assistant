针对小屏幕优化原文阅读，并支持点击文献直接打开正文。

- 列表行高从76压缩到32像素，默认标题优先；“详情列”可展开期刊、SI数和状态，悬停标题可查看完整信息。
- 压缩标题、按钮、页签和间距，窗口默认使用当前屏幕可用宽度。标题只显示“钙钛矿文献助手”。
- 点击列表自动打开正文，顶部下拉框切换正文/SI；缺少可预览附件时清空旧原文并显示原因。
- 不常用操作放在“更多阅读操作”；批注列表默认收起。高亮颜色、输入批注、保存高亮仍直接可用。
- PDF至少2倍像素密度渲染，显示比例与高亮位置不变，超大页面保留像素上限。
- 44项自动化测试，包含1280×720小窗口、自动打开、SI切换、快速切换、旧页面清空和高清坐标一致性。

更新时替换exe，继续选择原数据目录。使用端无需安装Python、Office或数据库。

限制：扫描图像本身缺失的细节无法补回；所有样本为明确标注的合成文档；未在干净Windows虚拟机及所有屏幕缩放组合验收。DOCX批注仍不写回原Word文件。PDF写回功能保留，入口移至“更多阅读操作”。
