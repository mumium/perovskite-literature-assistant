# 钙钛矿文献助手 v0.8.0 · MK Design

- 保留全部页面预览及MuPDF矢量绘制指令缓存。放大立即显示预览，随后在后台补清晰的可见区域，不再持续拉伸旧图片；无需重新打开PDF或提取文字。
- Shift+滚轮左右滚动，Ctrl+滚轮缩放。＋/－中间为缩放滑条，中点100%轻微吸附，拖出后正常缩放；双击恢复100%。百分比箭头按1%微调，移除独立100%按钮。
- 高亮按钮为黄色填充荧光笔，悬停显示Shift+H。选中已有高亮后变为取消标识，再点或按Shift+H取消；移除独立删除和复制选中按钮，保留Delete/Ctrl+C。输入框正常输入。
- 批注文字直接显示在PDF页内：拖动位置、拉右下角调尺寸、双击编辑；选中后设置字号与字体颜色，右键也可设置。位置、尺寸和样式自动保存。
- “保存批注”可另存或写回标准PDF高亮与FreeText文字框，包含中文、字体颜色和字号。工具内修改仍先存数据库，写回需主动操作，原文副本保持原哈希。
- 首次选文件夹后在其中建立“钙钛矿文献助手数据”子文件夹。已有库直接打开，不搬移旧数据；上次位置继续记忆。标题签名为MK Design。

旧库自动升级v4，升级前保存快照。预览图像预算512MiB，高清区域缓存另64MiB；文字、绘制指令及其他内存另计，超长文档仍需一定内存和首次加载时间。扫描件的原图分辨率无法通过矢量重绘增加。批注框限制在关联PDF页内，长批注可调框体或字号。DOCX批注仍用提取文本/列表。

77项自动化测试，覆盖0/90度旋转、绘制指令复用、高清倍率、滚轮、真实微调按钮点击、吸附、快捷高亮/取消与输入安全、批注拖动/缩放/样式/导出、旧库迁移与专用子目录。Windows单文件exe另进行只复制exe、移除外部运行环境路径并阻止网络的验收，检查高清、批注、导出和临时目录清理。测试文档均明确标注为合成，未在全新Windows虚拟机或公司受限电脑实测。
