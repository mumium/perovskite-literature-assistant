连续滚动阅读、快速缩放、逐字符高亮与直接编辑。

- 导入后直接导出分析包，取消待配对确认流程。旧库也无需补确认。关联附件仍从电脑浏览选择，角色可自行调整。
- 专题标签支持新增、重命名、删除与应用；左侧标签右键或顶部标签图标打开管理。
- PDF可连续滚动全部页，懒加载可见页和相邻页，缓存预算128MiB。缩放立即使用缓存，必要时再后台更新清晰度；超大页仍限制渲染像素。
- 页码下箭头向后、上箭头向前，去掉上一页/下一页按钮。支持单字母及跨页文字选择。
- 查找全文句子、高亮、删除高亮常驻；选中已有高亮后可按Delete删除。输入框内不抢占Delete。
- 文献信息、核心故事、工艺、性能和批注支持双击直接编辑。Enter或多行Ctrl+Enter保存，Esc取消，离开编辑框也保存。保留修订历史；科学核验仍独立进行，编辑内容会回到待核验状态。
- 双击批注列编辑，双击位置/原文列仍跳转。文献信息不再重复大标题或显示文章ID。
- 切换左侧文献保留当前页签。详情列新增通讯作者及完整名单提示。
- 顶部功能采用小图标和悬停说明，换库、备份、恢复等直接可见；主页面logo采用高清矢量图。
