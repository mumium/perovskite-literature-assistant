# 钙钛矿文献助手

Windows 64位离线便携桌面程序，v0.11.0。原始文件默认复制，数据与程序分离。界面为简体中文，标题签名 MK Design。

下载便携exe：[GitHub Releases](https://github.com/mumium/perovskite-literature-assistant/releases/latest)。源码仓库：[mumium/perovskite-literature-assistant](https://github.com/mumium/perovskite-literature-assistant)。

## 使用

1. 双击 `dist/钙钛矿文献助手.exe`，首次选择**存放数据的文件夹**，程序在其中自动创建 `钙钛矿文献助手数据` 子文件夹，以后自动打开上次的库，不把数据库和附件散放在所选父目录根部。选择已有库或包含上述子库的父目录会直接打开旧库；同名无关文件夹存在时新库自动编号，不覆盖其他文件。顶部“切换数据目录”同样支持，旧库不移动；命令行 `--data` 是明确指定实际库目录。无需安装Python、Office、数据库或模型，不使用注册表。
2. 点击“导入文件”“导入文件夹”，或拖入文件/文件夹。文件夹递归扫描，按SHA-256去重；批次报告会显示失败与不支持原因。
3. **先在左边点击正文文献，再点“关联附件”**，从Windows文件选择窗口浏览并多选PDF/DOCX/DOC，角色默认SI，点击“关联所选附件”。不需要在文章列表里猜目标；目标就是当前选中的文献，确认窗口显示标题与文件名。新文件自动复制，已导入的相同文件复用；原本属于其他文献的文件会移入当前文献并解除原关联。一篇正文可有多个SI、正文版本或预印本。“附件与配对 → 修改角色”可修改当前附件角色；“解除关联”将其恢复为独立文献。导入后可直接导出分析包，不再有逐个确认或待配对环节。文件名/DOI等候选不会强制合并文章。
4. 点击“导出分析包”。把ZIP带到联网电脑，解压后让ChatGPT或Codex按 `prompt.txt` 阅读 **manifest的全部文件、位置和文本**，参照 `result-schema.json`，填写 `result-template.json`。不要直接导回空模板。故事和工艺可分别提交，未完成的段请省略。
5. 点击“导回结果”，选择JSON，可多选。先校验文章ID、包ID、完整附件清单、实际哈希、类型、样品关系、证据ID和位置，再显示差异与引用匹配。格式错误的文件拒绝，合法文件可以分别导入。原文无法匹配的引用显示待核验。
6. 在“核心故事”“工艺”“性能与稳定性”“证据核验”查看；双击字段直接编辑；双击证据列跳转原文。PDF使用实际页，DOCX显示段落/表格行。原文引用匹配**不等于**科学结论已人工核验。
7. 文献信息、核心故事、工艺与性能可双击字段直接编辑并保存历史，详见下文。高级“人工修订 / 核验”窗口保留JSON与来源校验；核验前需阅读原文。已核验段不会被新AI结果覆盖，新候选可通过顶部“修订历史 / 待采用分析候选”图标查看。
8. 输入关键词搜索正文、SI、故事、工艺和笔记；期刊、年份、作者、材料、结构、专题、标签和处理状态可筛选。添加剂、工艺和性能术语可全文查找。Ctrl/Shift多选文章后点击“比较 / Excel”，导出关联表比较配方、样品、条件、缺失值和证据；第一版没有内置统一性能排名。

## macOS风格外观与深色模式（v0.11）

- 主界面与程序内弹窗采用macOS风格的灰阶表面、白色内容区、圆润紧凑控件、蓝色强调和细分隔线。按钮、输入/选择/数字框、复选项、菜单、滑条、列表和表格同步调整，右侧仍是分段式文字标签页。深色模式使用对应灰黑表面；文献检索栏保留紧凑尺寸，底部批注栏保持30逻辑像素。本程序仍为Windows应用，系统标题栏和原生文件选择窗口沿用Windows外观。
- 顶部图标工具栏默认透明无框。v0.10恢复明显的悬停淡蓝底色、按下更深底色和键盘聚焦反馈，始终没有外边框；深浅模式均适用，文字提示保留。右侧“文献信息、核心故事、工艺、性能与稳定性、证据核验、附件与配对、原文查看”继续使用文字标签页。
- 点击顶部工具栏最右侧的**月亮图标**切换深色模式，深色时变为**太阳图标**，再次点击恢复浅色。悬停显示功能说明。选择保存在当前数据目录的`config.json`中，重启、更新和目录搬移后仍保留，随完整备份保存；不同库可保存各自的外观。不联网、不修改注册表。
- 深色模式同步调整程序背景、表格、输入、弹窗和图标的对比度。PDF纸张、原文及页内批注保留原本颜色，DOCX高亮使用深色文字确保可读；界面切换不改写原PDF或导出内容。原logo与MK Design签名保留。
- 阅读区标题/附件选择独占上方一行；“阅读模式”“保存批注”与“适合宽度”同行。“修改批注”按钮已移除，双击批注列表的批注列或PDF页内批注框即可编辑。

## 界面、标签与直接编辑（v0.6）

- 顶部是小图标工具栏，悬停显示功能文字。文件/文件夹导入、关联附件、导出包、导回、复制提示词、API、Excel、标签、换库、联网配置、备份、恢复、历史及帮助均可直接点击。主页面logo直接采用任务栏/窗口的同一份ICO图案，按屏幕密度选择高清图层，不再使用重绘的SVG版本。
- 点击左侧文献会更新当前页签内容，保持你正在查看的文献信息、故事、工艺、性能或原文。原文仍自动准备对应正文；阅读区顶部下拉框可切换正文与SI。无附件或不可解析时说明原因并清空上一篇原文。
- 列表每行32像素，默认优先显示标题。“详情列”展开期刊/年份、SI数、处理状态和通讯作者，悬停可看完整名单。分类、列表和阅读区之间可拖动分隔线。
- 顶部标签图标或左侧标签区域右键打开管理。可新增、双击改名、删除，勾选应用到当前文献；改名/删除同步已有文献标签与检索，并保留历史。标签目录随数据备份保存。
- **手动分类（v0.7，v0.8.2支持双击改名）**：左上“手动分类”的＋创建类别，双击类别名称就地编辑，Enter保存、Esc取消，文献计数不进入编辑框；也可用✎或右键改名，−删除类别。“全部文献”和“未分类”是固定入口。按住清单中的文献拖入类别，Ctrl/Shift可多选；一篇文献可加入多个类别，不移动或复制附件。点击类别筛选，点击“全部文献”或“清空”退出分类筛选，“未分类”查看尚未归类文献。类别筛选可叠加全文与字段筛选；右键类别可将所选文献移出。删除类别只删归类关系，保留文献与附件。分类与专题标签独立保存，包含在完整备份、Markdown及Excel“手动分类”关联表内。
- “文献信息”直接双击内容列编辑，作者/单位/标签用分号或换行分隔；日期保留YYYY、YYYY-MM或YYYY-MM-DD精度。没有重复大标题和文章ID。
- “核心故事”双击正文条目直接写文字，声明类别可下拉调整；空项目“双击填写”可以直接录入。证据列双击定位。作者主张、直接结果、推测/建议仍分开。
- “工艺”“性能与稳定性”双击名称、描述或展开后的字段编辑。原文值、单位、标准化值、基准和换算说明分别保留；每个样品/测量独立。带＋的行可双击添加样品、步骤、参数、性能或测试条件。
- 单行Enter保存，多行Ctrl+Enter保存，Esc取消，离开编辑框也保存。编辑保留历史并将结论置为人工待核验；更改原文数值/单位会清空已过时的标准化数值/单位/换算说明，旧值可从历史找回。新标准化数值仍要求完整换算说明，科学核验需核对原文来源。

## 连续阅读、缩放与高亮（v0.8）

- **加速浏览 / 高清浏览（v0.11）**：“阅读模式”后的同尺寸渐变按钮显示下一步可切换的模式。默认高清模式，按钮为“加速浏览”；点击后改为固定预览图片缩放，不再补绘高清区域，按钮变成“高清浏览”。再次点击恢复原来的高清细节补绘。选择写入当前数据目录的`config.json`中的`pdf_browse_mode`（`fast`或`hd`），重启、更新、复制数据目录及完整备份后保留，不使用注册表。不同库可有各自选择。
- 加速模式冷启动PDF采用100%基准的固定预览，后续缩放只放大图片，放大后会较模糊；高清模式按需补绘原文字和矢量细节。切换时复用已加载页面、绘制指令、缩放、位置及批注，不重做全部页面；已有预览也直接复用。首次打开仍需读取全部页和文字层，速度受文件复杂度影响。加速主要减少放大及滚动时的高清绘制工作，不改变全文预载策略，也不影响DOCX文本显示、高亮证据或原文件。
- PDF所有页面连续纵向排列，可直接滚动翻页；页码下箭头从1到2、上箭头向前，也可输入页码定位。没有上一页/下一页按钮。阅读模式可隐藏左侧分类和列表。
- 点击＋/－、中间滑条、输入25%–400%，或Ctrl+滚轮缩放。滑条中点100%，拖动接近中点时轻微吸附（滑条±3格），拖出该范围恢复自由缩放；双击滑条恢复100%。百分比框箭头按1%微调，不受吸附影响。“适合宽度”适配阅读区。Shift+滚轮可左右滚动超宽页面。
- v0.9.1滑条增加倍率刻度尺，25%、100%、400%始终显示，100%刻度突出；空间足够时显示50%、200%、300%，窄屏自动精简文字避免重叠。细刻度按实际滑动位置排列，左半段25%–100%、右半段100%–400%，沿用100%居中设计。深浅模式均可见，控件保持30逻辑像素高度。
- 首次打开PDF后后台**预解析全部页绘制指令（MuPDF DisplayList）并加载全部预览**，记忆的当前页优先；显示进度，可暂停/继续，失败页可重试。首次加载耗时取决于页数和图片复杂度。
- **原文快速切换（v0.10）**：本次运行中保留最近打开的PDF页面、绘制指令、高清区域、缩放与横纵阅读位置，返回已缓存原文时立即恢复，不重新打开PDF或预载页面；未加载完的只补剩余页。PDF与DOCX之间切换、暂时选中无附件文献也保留缓存。DOCX复用提取文本的文档对象、字号与位置，批注始终刷新自数据库。
- v0.10.1补充适合宽度下的定位：在另一篇文献中改变窗口宽度或切换阅读模式后返回，按原页及页内相对位置恢复，无需重新预载。
- PDF缓存最多保留最近12份附件，所有缓存PDF的预览和高清图像合计预算1GiB；单份预览仍采用下述512MiB预算。达到上限会释放最久未访问的原文，并在状态栏说明，返回被释放的文献时重新预载。文字、绘制指令、控件及引擎开销另计，这不是总进程内存上限。DOCX缓存最多12份，文本占用估算预算64MiB。关闭程序或切换数据目录时释放，本地原文件和分析数据不受影响；重新启动后首次阅读仍需加载。
- 缓存以附件ID、实际路径、SHA-256登记值区分，返回时快速检查文件大小和时间戳；可检测到文件变化时不复用旧页面，重新进行完整哈希校验。首次打开PDF、导出分析包及原PDF写回仍校验完整哈希。这里的缓存仅用于阅读，不代替证据或分析结果的校验。
- 缩放立即复用预览，短暂停顿后仅为可见区域补充高清画面；从原文字/矢量绘制指令重绘，避免放大旧图片造成文字持续模糊，也不重新打开PDF或提取文字。已有高清区域缓存可复用。扫描件或原图低分辨率本身无法凭空增加细节。
- 全文预览图像预算512MiB，超长或大幅面文档会明确提示预览分辨率调整；仍加载全部页。可见高清区域另有64MiB缓存，每块最多1600万像素；文字坐标、绘制指令及引擎/程序其他开销另计，这些预算不是总进程内存上限。首次打开、分析包和原PDF写回继续校验哈希，预载/高清期间检查文件变化。
- 拖选支持单个字母/汉字和跨页选区，双击扩展句子。选颜色、输入可选批注，点击**黄色填充荧光笔图标**或按 **Shift+H**。蓝色为选区，保存后四色高亮；证据定位有紫色边框。
- “查找句子”常驻，搜索整个PDF，定位匹配页面；重复文字会选择该页匹配区域，只需标某处时直接拖选字符。复杂阅读顺序、特殊连字或扫描图片仍受PDF文字层限制，无OCR时不能恢复不存在的字符。
- 点击或重新拖选已有高亮，图标变为带取消标记的荧光笔，悬停提示“取消高亮（Shift+H）”；再点或按Shift+H取消，图标恢复。Delete仍可删除所选高亮。独立删除和复制选中按钮已移除，Ctrl+C及右键复制保留；文字输入框中Shift+H正常输入，Delete正常删字。
- 批注列表的批注列双击编辑，位置和原文列双击跳转。批注列表可折叠，查找与高亮图标常驻。
- **PDF页内批注框**：有批注内容的高亮会在页面显示文字框。拖动框体移动，拖动右下角调整尺寸，双击编辑多行内容；选中后用底部字号（6–48 PDF点）和字体颜色按钮调整，右键也可设置。位置和尺寸使用页面坐标，随缩放保持关联，跨重启、目录搬移和备份恢复保留。批注框限制在所关联页面内，文字多时可拉大或缩小字号。DOCX继续使用提取文本和批注列表，不虚构PDF页内位置。
- 底部高亮颜色、批注输入、荧光笔、字号、字体颜色及批注列表统一为30像素逻辑高度和相同边框风格。字号使用“− / ＋”独立大按钮，每次1点，也可在中间完整显示的“字14”等字号框内直接输入；达到6或48时对应按钮禁用。字体颜色图标为彩色渐变A，选中PDF批注后可用。
- DOCX可直接选择提取文本高亮并缩放字号，位置为段落/表格行与字符范围，不虚构页码。
- 高亮、批注及其位置样式先自动保存数据库，不自动改写PDF/DOCX，参与全文检索与Markdown/Excel导出。点击“保存批注”可另存或写回标准PDF高亮及可编辑文字批注框，位置、颜色和字号一并保留。
- 旧库首次打开自动升级到数据库版本4，升级前在migrations保留对应旧版本快照。原文献、附件、分析及高亮均保留；更新后继续使用原数据目录即可，不自动搬移旧库。

## 把高亮和批注保留在PDF文件里（v0.3）

在“原文查看”保存好高亮/批注后，打开“保存批注”，有两个入口（包含标准高亮和FreeText页内文字批注）：

1. **另存带批注 PDF…**：生成包含标准PDF高亮与评论的文件，默认保存在数据目录 `annotated/`。把这一个PDF发给别人，对方用支持批注的PDF阅读器即可查看，无需本工具或数据库。
2. **写回原 PDF…**：选择最初导入的原PDF，点击“写回并备份”。写入前会将现有文件备份到数据目录 `pdf_backups/`，成功窗口会显示备份路径。

重复写入会更新本工具的颜色/批注，移除在工具中已删除的高亮；原PDF中其他阅读器已有的批注保留。修改工具内标注后，需要再次点击上述按钮同步到PDF，不会自动写入外部文件。

程序会检查目标是否与当前文献对应。原PDF若已被其他软件修改，或选到了另一篇文章，会拒绝覆盖；此时可另存副本。带数字签名的PDF不允许直接写回。文件正在被其他程序占用、目录不可写时会报告原因。

工具导入时保存的库内原文副本保持原哈希，已有AI分析包与证据不会因为导出批注而失效，因此不能覆盖 `files/` 内的受管理副本；写回时请选择最初导入的外部原PDF。写入记录和原文件备份随完整数据备份保留。

**DOCX暂不支持将高亮/批注写回Word文件**，仍保存在数据库，可通过Markdown/Excel导出。PDF批注的显示和弹出评论操作取决于阅读器；本工具写入标准可编辑注释，没有把高亮压成图片。

## 数据与更新

所有数据库、附件、分析/API配置、分析包登记、中间分析结果均位于选择的数据目录。附件相对路径以 `files/` 开头，整个目录可复制或搬移；移动后选择新目录。更新时替换exe即可保留数据。不要选程序临时解包目录。

上次数据目录的位置单独记在exe旁的 `startup-location.json`（Python版在源码根目录），只含路径和版本，不含文献内容或Key。同盘时使用相对路径，程序与数据一起搬移后仍能定位；跨盘时保存绝对路径。程序目录只读时改存 `%LOCALAPPDATA%/PerovskiteLiteratureAssistant/`，优先采用较新的记录；两处均不可写时显示原因，文献库仍可正常使用。记忆文件不放临时解包目录、不写注册表、不随分析包或数据备份导出。删除此位置记录不会删除文献；下次启动重新选择。换库不会移动或删除原数据。

**不要同时编辑同一数据目录。** 同机程序以目录锁阻止并发打开；复制的数据目录在不同电脑属于独立副本，不自动同步和合并。跨电脑移动前请关闭程序，优先用顶部“完整备份”图标，在另一电脑“恢复到空目录”。恢复不会覆盖现有库，校验SQLite完整性和附件哈希。备份含所有附件、结果、历史、配置和API断点，不含Key。

程序无需管理员权限，不修改注册表，不安装服务，不添加启动项。单文件exe启动会由PyInstaller解包到Windows临时目录，正常退出清理；程序数据始终写入用户选择的目录。异常断电或系统强杀后，临时运行文件可能由系统保留；不影响库内数据。

## 可选联网

默认关闭，无启动网络请求或依赖/模型下载。顶部“联网配置”图标允许主动开启，配置OpenAI兼容API基础地址（通常含 `/v1`）、模型名、Key及超时。Key只保留在本次进程内存，关闭后需重填，不写入配置、日志、包、备份或导出。

“Crossref候选”仅发送所选DOI，结果追加候选，不覆盖元数据；只读取发表字段，忽略created/deposited/indexed日期。日期保留原精度。作者顺序不用于猜通讯或共同第一作者。

点击“API分析”才发送所选文章及全部配对SI的提取文本。按全部位置分块提取，再综合，完成块存于数据目录 `api_jobs/`，重试可继续。取消在块之间立即生效；在途HTTP请求最多等所设超时，不强杀线程。网络/429/服务端临时错误最多重试3次。返回JSON先校验再进入导入预览。用量由服务商返回时显示。ChatGPT订阅不自动包含API权限。

最终综合笔记大于180000字符时明确停止，不静默截断，改用离线分析包分阶段综合。不同模型的上下文上限需要用户按服务商能力选择。第一版未使用真实付费API进行端到端验收。

## 第一版支持范围

- 可靠目标为有文字层的PDF和正文段落/表格型DOCX。无OCR，扫描PDF、无文字页、加密、损坏、旧DOC都有显式状态。混合PDF部分页缺文字时为“部分页无文字”。
- PDF表格以文本位置保留，图片/复杂布局表格尚不能自动结构识别；DOCX提取主文档段落及表格，文本框、嵌入对象、图片、脚注、页眉页脚尚需人工对照原件。PDF可原页查看，DOCX原件保留但内置查看器只展示提取内容。
- 本地元数据仅提供首页标题、明确标识DOI、显式Authors行和文件名候选。多DOI保持歧义，不自动选取；复杂排版作者/单位/日期需人工或Crossref核验。所有候选有文件来源，人工修订有历史。
- 元数据、故事和工艺性能支持字段直接编辑；高级来源修订和科学核验保留JSON窗口。性能比较以带来源的Excel为主。搜索为SQLite FTS5和子串补充，不含向量检索。
- 工艺字段以具名参数保存，覆盖层序、清洗、配方、旋涂、反溶剂、退火、后处理、沉积、面积和测试条件；每个样品独立。未报告为null，标准化值需换算说明。程序校验格式和来源存在性，无法自动证明AI提取的科学语义与单位换算正确，需人工核验。
- 无内置大语言模型，不会离线自动生成阅读卡；通过分析包或可选API获得AI结果。

详见 [数据与交换格式](docs/数据与交换格式.md)、[验证记录](docs/验证记录.md) 和 [后续功能与使用场景](docs/后续功能与使用场景.md)。

## 源码开发与构建

开发端需要Windows 64位Python 3.12及网络，仅构建电脑需要；使用端无需安装。主要依赖固定于 `requirements.txt`，本次完整构建环境保存在 `requirements-lock.txt`。使用PySide6-Essentials提供QtCore/QtGui/QtWidgets/QtSvg，避免捆绑不使用的浏览器引擎。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

已经安装依赖可运行 `build_windows.ps1 -SkipInstall`。构建失败会停止，不会伪造exe。脚本默认 `--onefile --windowed`、无UAC提升要求，SHA256写入dist。

```powershell
# 包内合成自检，不需Python/Office/联网（输出目录应为新目录）
.\dist\钙钛矿文献助手.exe --self-test "D:\测试输出 新目录"
# GUI及PDF预览自检，短暂显示窗口后退出
.\dist\钙钛矿文献助手.exe --smoke-test "D:\界面自检 新目录"
# 可选命令行指定数据目录
.\dist\钙钛矿文献助手.exe --data "D:\我的文献库"
```

自检创建的是明确标注的虚构测试文档，不能用于科研结论。退出码0为通过；报告写入所选输出目录。保留测试源码以便后续复验。

PyInstaller单文件方式及Qt后台线程方案参考 [PyInstaller官方文档](https://pyinstaller.org/en/stable/operating-mode.html) 和 [Qt官方线程信号示例](https://doc.qt.io/qtforpython-6/examples/example_widgets_thread_signals.html)。
